# Generalist diagnostic rubric

Ground truth is 10, independently established by direct four-subset enumeration and a bitmask recurrence before provider calls. This file is evaluator-only and must not appear in worker packets.

For each report record: exact answer correct, method complete enough to reproduce, coverage of all 210 candidate subsets, proof of no duplication, handling of the false note, honest treatment of unexecuted code, and observed provider calls. A terminal run is not automatically a correct answer. Compare both conditions on identical question and source bytes. Record any protocol failure and every retry.
